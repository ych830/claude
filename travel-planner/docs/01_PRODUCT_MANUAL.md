# 제품 기능 매뉴얼

## 1. 개인화된 AI 여행 일정 생성

### 설명
사용자의 취향 정보를 입력받아 LLM 기반 API로 맞춤형 여행 일정을 생성합니다.

### 입력 정보
- 성별
- 나이
- 동반자 유무
- 동반자 유형: 혼자, 친구, 연인, 가족, 단체
- 과거 여행 이력
- 여행 목적: 휴식, 맛집, 액티비티, 쇼핑, 자연, 역사, 사진, 핫플 등
- 여행 기간
- 여행 지역
- 예산 범위
- 이동 수단 선호도

### 출력 정보
- 일자별 여행 일정
- 시간대별 장소
- 장소 설명
- 예상 이동 시간
- 예상 예산
- 추천 이유

## 2. SNS 게시물 기반 일정 생성

### 설명
인스타그램, X, 블로그 등의 게시물 링크를 입력하면 해당 게시물에서 장소 정보를 추출하여 여행 일정으로 변환합니다.

### 주요 처리
1. URL 입력
2. 게시물 내용 수집 (크롤링 또는 파싱)
3. 장소명 후보 추출
4. 지도 API로 실제 위치 검증
5. 중복 장소 제거
6. 일정표 또는 추천 리스트 생성

### 주의 사항
- 각 플랫폼의 크롤링 정책을 확인해야 합니다.
- 로그인이 필요한 게시물, 비공개 게시물은 처리 제한이 있을 수 있습니다.
- 초기 버전에서는 블로그/공개 웹페이지 중심으로 시작하는 것이 안전합니다.

## 3. 직관적인 지도 기반 인터페이스

### 설명
일정에 포함된 장소들을 지도 위에 표시하고, 일정 순서에 따라 경로를 확인할 수 있게 합니다.

### 주요 기능
- 일정 순서대로 마커 표시
- 장소 카테고리별 마커 구분
- 다음 목적지까지 거리 표시
- 도보, 대중교통, 자동차 이동 시간 표시
- 지도 하단 또는 측면에 일정표 표시

---

## 4. 일정표 열람 및 수정

### 설명
생성된 일정을 사용자가 직접 수정하거나 초대된 사용자와 함께 편집할 수 있습니다.

### 주요 기능
- 일자별 일정 열람
- 드래그 앤 드롭으로 순서 변경
- 장소 추가/삭제
- 장소별 메모 작성
- 공동 편집 (WebSocket 기반)
- 수정 시 지도 즉시 반영

---

## 5. 실시간 관광지 정보 및 사용자 팁 제공

### 설명
관광지의 운영시간, 입장권 가격, 리뷰 요약, 사용자 팁 등을 제공합니다.

### 주요 기능
- 운영시간 표시 (Google Maps / Kakao Map 연동)
- 입장권 가격 표시
- 예약/티켓 구매 링크 연결
- 사용자 리뷰 작성
- 비추/쏘쏘/강추 3단계 평가
- AI 리뷰 요약
- 꿀팁 란 제공

---

## 6. 카테고리 분류 및 추천

### 설명
관광지, 식당, 호텔, 카페, 쇼핑, 액티비티 등으로 장소를 분류합니다.

### 주요 기능
- 일정 내 장소 카테고리 표시
- 특정 장소 주변 추천
- 카테고리별 필터
- 사용자 취향 기반 추천 가중치 적용

---

## 7. 평균 예산 기능

### 설명
일정별 예상 비용을 계산합니다.

### 계산 항목

- 식비

- 입장권

- 예약 시간 알림
